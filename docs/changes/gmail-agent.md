# Gmail urgency agent

Added an independent, on-demand Gmail metadata scanner and a dashboard view for its flagged inbox digest. Project access is explicit. The result stays visible in the email project and out of model inputs. The setup guide documents the required Google consent and local variables.

ESLint, type checks, the dashboard build, 23 unit tests, 10 Floci integration tests, and one browser regression test passed. Google requests were simulated in tests. No live mailbox was connected or read.
